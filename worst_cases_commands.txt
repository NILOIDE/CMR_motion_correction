1. Rank the subjects (re-run whenever more subjects have finished; ~15 s)
-----------------------------------------------------------------------
Runs on the server (python3, standard library) and writes one list per metric to worst_cases\<metric>.txt, worst
first: subject, value, and the slice / view / intersection where it is worst.

python worst_cases.py --remote stol@131.159.110.9:/vol/miltank/projects/ukbb/data/cardiac/slice_alignment/aligned_subjects --top 50

Options: --top N (subjects per list), --min-points N (per-slice / per-line Dice and NCC only where the line has at
least N points; default 20), --metrics <names> (only some lists).


2. View a list
--------------
Each subject is downloaded once (~30 MB) into %USERPROFILE%\.cache\cmr_slice_viewer\ when shown; the next one in the
list is fetched in the background. ] / [ (or PageDown / PageUp) step through the list, worst first. The slice named in
the list is the one profiled first (intersection panes on the right).
Useful keys: Home = acquired geometry (step 0), b = best pose, i = sampling lines, m = dilated masks,
k = SA-SA lines, u = long-axis radius, , / . = profile the previous / next slice.

Every command below is the same viewer call; only --subjects (and the start options) change.
